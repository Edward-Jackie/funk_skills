# 本地表单收集

用一个本地 HTML 页面收集比 `AskUserQuestion` 更丰富的结构化信息（开放文本、多选、滑块等），
用户填完复制粘贴回来，我直接解析。全程不发一次网络请求，不需要发布到 claude.ai。

## 什么时候用这个，而不是 AskUserQuestion

- 问题超过 4 道，或者需要开放式文本、多选、数值滑块这类 `AskUserQuestion` 不支持的题型 → 用这个
- 4 道题以内、答案都是固定选项里选一个 → 直接用 `AskUserQuestion`，全自动回传，不用走表单这一套

## 怎么做

1. 复制 `template.html` 到一个临时文件（比如项目的 scratchpad 或 `~/Desktop/`）。
2. 按当前对话实际需要的问题，编辑里面的 `<fieldset>`：增删题目、改文案。**每个 fieldset
   用 `data-key`（中文键名）和 `data-type`（题型）声明，JS 已按 data 属性通用收集，不用再手改
   `collectAnswers()`。** 新增题复制任一 fieldset 改 data 属性和文案即可。
3. 三道关键点：
   - **跳过此题**：每题自带，勾选后该题键记为 `null` 并加一个 `《键名（跳过）》` 标记。
   - **自己填（其他）**：单选/多选若要允许自由输入，加 `data-other="true"`，并在选项里放一个
     `value="其他"` 的项；用户填了字会合并成 `其他：xxx`。
   - 题型：`text` / `textarea` / `radio` / `checkbox` / `range`。
4. 配色/字体可以按当前对话主题调整，默认是一套中性深色方案，不强制照搬。
5. 用 `open <path>` 直接在本地浏览器打开，不要用 Artifact 工具发布到官网（用户偏好本地模式）。
6. 提示用户填完点"一键复制 JSON"，粘贴回聊天框；"改成下载文件"是复制被浏览器拦截时的兜底选项。
7. 用户粘贴回来的内容就是一段 JSON 文本，直接解析，不需要额外确认。
8. 解析时注意：键值可能是 `null`（表示跳过这事），或 `其他：xxx`（表示选了"其他"自己填的），
   别当成缺数据报错。

## 已知的坑

- **剪贴板 API 在 `file://` 页面不保证能用**：`template.html` 里已经带了 `execCommand('copy')`
  兜底，改表单内容时不要动 `copyText()` 这个函数。
- **别手改 `collectAnswers()`**：取值逻辑已按 `data-key`/`data-type` 通用化，缺题型再补 if
  分支，不要为单个字段单独写取值键，否则回传会缺键。
- **「其他」只在 `data-other="true"` 的题型里出现**：`range` 和 `text` 不会显示"自己填"输入框
  （文本本身就能自由输，滑块自由填没意义）；跳过每题都有。
- **不要用 `echo '<json>' | stdin` 这类方式往外传数据**：跟 JSON 无关，这条是历史教训，
  Bash 工具会把内联字符串里的 `\n` 转成真换行，凡是要落 JSON/多行内容到文件，用 Write 工具。
