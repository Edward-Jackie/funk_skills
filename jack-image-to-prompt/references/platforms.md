# 各生图平台语法规则

## 通用英文（最保险）

逗号分隔的短语流。任何模型都吃得下。

```
{主体}, {构图}, {风格}, {光照}, {技术}, color palette {色值}
```

尾部补两句自然语言约束：

- 有文字：`Text in image reads verbatim: "{原文}".`
- 长宽比：`Aspect ratio {w}:{h}.`

**为什么要补这两句**：逗号短语流表达不了"照抄文字"和"画面尺寸"这两种强约束，必须用完整句子讲。

**兜底**：如果模型的英文部分为空（没按双语格式答），回退用中文整段，**不能输出空串**。

---

## Midjourney

在通用英文基础上：

```
{通用英文，去掉句尾句号} --ar {w}:{h} --style raw --q 2
```

- `--ar` 从 `[技术]` 字段里正则抽 `数字:数字`
- `--style raw` 减 MJ 的默认美化，提高忠实度
- `--q 2` 最高质量

**注意**：`renderEn` 输出的尾部 `Aspect ratio 1:1.` 要先用正则删掉，否则会和 `--ar` 重复。

---

## Stable Diffusion / Flux

分正向、负向两段。

```
PROMPT: {主体}, {构图}, {风格}, {光照}, color palette {色值}, masterpiece, best quality, highly detailed

NEGATIVE: blurry, lowres, jpeg artifacts, watermark, signature, deformed,
extra limbs, extra fingers, bad anatomy, oversaturated, low contrast
```

**关键点**：

1. **构图必须进正向词**。初版漏了 `[构图]`，SD 直接把机位和景深丢光——这是 SD 和 MJ 最大的差异点。
2. **色值塞 `color palette`**，SD 对具体色值响应好。
3. **画面无文字时，负向词追加 `text, letters, words, caption`**。有文字时则不加，否则会把该出现的字也压掉。

---

## DALL·E / GPT Image

自然语言长句，不要逗号堆叠。

```
请生成一张图片。{中文描述}。 严格保持上述数量、位置关系和文字内容，不要自行增删元素。
```

**为什么用中文**：这类模型对自然语言指令遵循度好，中文描述 + 明确约束比英文短语流更稳。

**为什么末尾加那句**：这类模型倾向于"自由发挥"，会自行改数量和谐布局，必须显式禁止。

---

## 即梦 / Seedream

中文自然语言，参考 DALL·E 的句式，但侧重质感词：

```
{中文描述}，{风格}质感，{光照}，{色板}
```

即梦对"质感""氛围"这类词响应明显，可以适度加：

- 电影感光影、柔焦、胶片颗粒、高级感

**注意**：不要堆砌。堆超过三层质感词反而会糊。

---

## 通用：`[文字]` 字段怎么塞

| 平台 | 写法 |
|---|---|
| 通用英文 | `Text in image reads verbatim: "原文".` |
| MJ | 同上（MJ 对文字控制弱，别指望） |
| SD | 正向词直接放 `"原文"`，**且不加 text 负向词** |
| DALL·E / GPT | `画面内文字原文为「原文」，不要翻译。` |

**统一规则：不翻译。** 原文是什么就照抄什么。
