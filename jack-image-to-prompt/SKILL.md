# 图片反推 Prompt

## 核心原则

**只有一步交给模型，其余全是确定性代码。**

```
图片 → [1] 像素采样 → [2] 模型拆解 → [3] 字段解析 → [4] 语法渲染
        canvas        多模态API      契约解析        按平台分叉
        ↑确定性          ↑唯一模型步骤      ↑确定性        ↑确定性
```

只要某项能被确定性方式算出来，就绝不交给模型。这条是整个 skill 的地基。

## Quick Start

**推荐路径：用 HTML 工具**

```bash
open ~/.claude/skills/jack-image-to-prompt/assets/workbench.html
```

载图 → 填接口配置 → 自动拆解 → 勾选目标平台 → 复制。

**批量路径：用脚本**

```bash
# 单张图，输出 JSON
python3 scripts/analyze.py --image ref.png --out result.json

# 批量打标（LoRA 数据集）
python3 scripts/batch.py --dir ./images --out ./captions.jsonl
```

## 三条契约（不可破坏）

### 契约一：字段字典

模型必须按这八个字段名逐行输出。渲染器靠字段名做映射，**改名即断**。

| 字段 | 内容 | 用途 |
|---|---|---|
| `[主体]` | 数量 / 姿态 / 朝向 / 材质 / 表情 | 正向词主力 |
| `[构图]` | 焦段感 / 视角 / 位置占比 / 景深 | SD 必须包含，否则构图丢失 |
| `[光照]` | 光源方向 / 色温 / 软硬 / 轮廓光 | 正向词 |
| `[色彩]` | 色值 / 对比度 / 饱和度 | **降权为参考，真实色板来自采样** |
| `[风格]` | 媒介 / 流派 / 质感 | 正向词 |
| `[技术]` | 清晰度 / 噪点 / 颗粒 / 长宽比 | 抽两样：长宽比、噪点 |
| `[文字]` | 逐字照抄原文 | 单独处理，不翻译 |
| `[一句话总述]` | ≤40 字 | 人类可读摘要 |

### 契约二：双语输出格式

```
[字段名] 中文 | English
```

多个描述点用 `/` 分隔，**不要用逗号**。

**为什么是"模型生成双语"而不是"代码按语种过滤"**：
初版用事后过滤，模型固定用中文回答，英文模板被滤成空，SD 和 MJ 输出为零。
双语必须由模型原生生成，不能让代码猜。

### 契约三：解析容错

- 无 `|` 分隔 → 整段当中英通用，**保证不渲染成空**
- 字段缺失 → 跳过，不报错
- 模型没按格式答 → 回退原始文本
- `[文字]` 字段 → **整段照抄，绝不拆竖线、绝不翻译**

## 禁令清单

| 项 | 规则 | 依据 |
|---|---|---|
| 色板 | canvas 采样，模型禁止参与 | 模型报 `#A8C0E0`，实际 `#88A8D8`，亮度差 40 |
| 长宽比 | 从原图读，不从模型输出解析 | 模型所述尺寸可能与源图不符 |
| 文字 | 整段照抄，不拆不译 | 拆竖线会把 `PNG` 切成两半 |
| 字段名 | 固定八个，不可增删 | 渲染器靠名字映射 |
| 接口密钥 | 不落盘、不进日志、不进 prompt | 见 `references/security.md` |

## 能力边界（必须对用户说明）

- **不承诺 100% 还原**。纯文字通道语义天花板 90~95%，是硬约束不是调参问题。要更高得让生成模型吃参考图，走编辑模式——那属于另一个 skill。
- **不承诺精确计数**。模型会主动标 `unknown`，但不会纠正自己数错。
- **不处理小字号文字**。大字号能读对，画面里的微小文字只能 `unknown`。
- **不做敏感内容**。硬线。
- **不做参考图条件**。

## 平台语法速查

详见 `references/platforms.md`。核心差异：

| 平台 | 关键点 |
|---|---|
| 通用英文 | 逗号分隔，最保险 |
| Midjourney | 抽长宽比塞 `--ar`，尾部 `--style raw --q 2` |
| SD / Flux | 正向 + 负向两段，构图必须进正向词 |
| DALL·E / GPT | 自然语言长句，末尾加"不许增删元素" |
| 即梦 / Seedream | 中文自然语言，强调质感词 |

## 实测踩坑记录

**这部分是花了一轮真实测试换来的，比流程描述值钱。** 详见 `references/pitfalls.md`。

三个最关键的：

1. **色值必须采样**。任何让多模态模型"报色值"的方案都会翻车。
2. **双语必须模型生成**。事后按语种过滤会把一种语言整个滤空。
3. **系统代理会掐断请求**。`curl` 报 `EXIT=56` / `CONNECT aborted` 时加 `--noproxy '*'`。
