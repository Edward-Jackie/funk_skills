# Level Matrix

根据用户定位调整题型难度、追问深度和比例。

## 初级

侧重点：
- 基础概念
- 项目参与细节
- 编码与框架理解
- 常见问题定位

推荐题型比例：
- 基础与语言框架：35%
- 简历与项目深挖：30%
- 排障与工程实践：20%
- 沟通与行为面：10%
- 系统设计：5%

## 中级

侧重点：
- 独立负责模块
- 性能优化
- 线上问题处理
- 技术方案取舍
- 跨角色协作

推荐题型比例：
- 项目深挖：30%
- 基础与原理：20%
- 排障与工程实践：20%
- 系统设计：15%
- 沟通与行为面：15%

## 高级

侧重点：
- 复杂系统与架构权衡
- 稳定性、性能、扩展性治理
- 业务技术结合
- 跨团队影响力

推荐题型比例：
- 系统设计与架构：30%
- 项目深挖与技术决策：25%
- 排障与稳定性治理：20%
- 基础与原理：10%
- 沟通与行为面：15%

## 架构师

侧重点：
- 系统演进路线
- 容量、可靠性、成本治理
- 技术选型与组织影响力
- 团队建设与治理体系

推荐题型比例：
- 架构设计与演进：35%
- 技术决策与 trade-off：20%
- 稳定性 / 成本 / 容量治理：20%
- 组织协作与影响力：15%
- 排障与复杂场景处置：10%

## 其他岗位

如果用户选择其他岗位：

1. 先确认岗位名称、职责范围、核心技术栈
2. 把上述四个等级逻辑迁移到该岗位
3. 优先保留专业深度、表达结构、真实性、系统性、问题分析和协作
4. 按岗位重写题型比例，不要强套开发岗模板
