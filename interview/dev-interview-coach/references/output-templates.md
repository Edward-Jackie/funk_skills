# Output Templates

以下模板用于稳定输出结构，可按岗位微调，但不要删掉关键栏目。

## Opening Template

```text
你好，我会根据你的简历、目标公司和岗位信息，模拟一场更贴近真实场景的技术面试。

开始前我先确认这些信息：
1. 你的目标定位：初级 / 中级 / 高级 / 架构师 / 其他岗位
2. 你的岗位方向：后端 / 前端 / 全栈 / 移动端 / 测试开发 / SRE / 数据 / AI / 其他
3. 你希望的训练模式：模拟面试 / 专题训练 / 先分析建议再决定
4. 你希望的交互形式：语音模拟 / 文字输入模拟
5. 你希望的作答方式：一题一题拆解后总结 / 先统一作答后复盘
6. 你最想重点训练的方向：技术基础 / 项目深挖 / 系统设计 / 排障分析 / 沟通表达 / 综合模拟

如果公司信息或 JD 不完整，我会先补齐岗位侧重点，并把推断项单独标注。
```

## Single Question Template

```text
本题我重点观察：技术深度 / 表达结构 / 项目真实性。

第 N 题：
<问题正文>

请尽量按这个顺序回答：
1. 背景或问题定义
2. 你的职责或判断
3. 方案与关键取舍
4. 结果与验证方式
5. 复盘
```

## Full Review Template

```text
本轮模拟结束，下面是你的复盘结果。

一、总体评价
<一句到三句，说明当前水平更接近哪个层级、优势和主要短板>

二、评分维度
- 技术深度：X/10
- 表达结构：X/10
- 项目真实性：X/10
- 系统性：X/10
- 排障思路：X/10
- 沟通协作：X/10

三、表现较好的地方
- <2-4 条>

四、错题集 / 高风险追问点
- <2-6 条>

五、当前能力短板
- <2-4 条>

六、提升建议
- <2-5 条>

七、学习路径建议
- <按 1 周 / 2 周 / 1 月，或按主题拆分>

八、项目补强建议
- <补充指标、排障案例、主导决策、协作证据等>

九、下一轮训练建议
- <下一轮优先练什么>
```

## Post-Review Coaching Template

```text
在刚才这轮题里，你觉得自己最容易卡住的是哪一类题？

你可以直接告诉我更接近哪一种：
- 知识点不会
- 知识点会，但表达不清
- 项目经历真实，但亮点和证据不足
- 一被追问就乱
- 排障思路没有体系
- 系统设计不知道怎么展开
- 面试时容易紧张

没关系，这些卡点本身就是最值得训练的突破口。
你已经具备了 <已有优势>，我们接下来重点把 <关键短板> 补成一套稳定的答题方法。

下一步我会：
1. 帮你定位问题根因
2. 给你一个更适合你的答题框架
3. 设计下一轮针对性训练
```
